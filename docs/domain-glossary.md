# Yaha Desk 领域词汇

本页是开源客户端、固件和公开需求记录共用的命名基线。云端具体实现可以位于独立仓库，但不得改变这里的用户语义。

| 词汇 | 含义 |
| --- | --- |
| 桌面设备（desk device） | ESP32-S3 麦克风与桌面工作台；通过 BLE 向 Mac 送音频，通过 Wi-Fi 获取获授权的业务数据。 |
| 设备首页（desk home） | 默认页面：时间、日期、Mac 状态环、通知条和可选的工作台入口。 |
| 健康总览（desk overview） | 任务、采集、处理、GLM 与小程序五个云端分区的聚合状态；无权分区只显示不可用原因。 |
| 工作台告警（desk alert） | 总览中需要关注的失败、失联、断流、积压或冷却项；不是设备控制指令。 |
| 快捷操作（desk action） | 用户在设备上长按确认的重试、补跑、取消、暂停或恢复；不包含发布、删除、审核或开麦。 |
| 设备推送（desk feed） | 经 `desk_feed` 返回、设备尚未显示的最新文章或日报卡片。 |
| 设备卡片（desk card） | 设备显示的标题、正文与 TTL；讲话时让位，到期自动消失。 |
| 设备专用应用（device application） | 由 `desk_prepare_device` 为当前用户创建并绑定的公开 OAuth 客户端；强制 PKCE，不持有客户端密钥。 |
| 设备授权（device grant） | 用户在浏览器明确同意设备所需 scope 后签发的授权；准备应用不等于完成授权。 |
| 设备上报（desk report） | 固件通过 `desk_monitor` 上报版本、网络、静音、Mac、DMS 与网盘设备状态；讲话期间暂停联网。 |
| 暂时断开（link paused） | Mac 主动停止扫描并断开 BLE，把唯一连接让给 iPhone 配置；恢复连接或重启 App 后恢复。 |
| 录音备份（recording backup） | 一次开麦到静音/断开的 Ogg Opus 录音；默认先存 Mac，再按用户授权上传网盘。 |
| 本人声纹档案（personal voice profile） | 用户明确录制的本人语音、质量结果与本地 embedding；不等于降噪或说话人分离。 |
| 本地听写（local dictation） | 按住 Fn 时复用同一 PCM 采集链路，由本地 Qwen3-ASR 输出一次最终文本；不经过输入法听写链路。 |

## 不变量

- 静音状态只有一个权威入口；云端或远端只能静音，不能远程开麦。
- Fn、PCM capture 和最终文字写入各只有一条主链路，不能并行启动第二套录音器或输入法宿主。
- 用户语音、声纹、OAuth token 与网盘令牌不进入公开仓库。
- 设备控制与业务数据同步分层：DMS/MQTT 承载设备控制，MCP 工具承载获授权的业务数据与状态。
