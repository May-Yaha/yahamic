# 桌面设备页面轮播（2026-11-03）

## 目标与已确认范围

用户确认固定模板：像素时钟、Mac 状态与相关电量、通知（最新文章、AI 日报、agent 消息）。Mac App 可预览、启停、排序、独立设置停留时间；即使没有 BLE 连接也能直接保存至云端，设备联网后同步。云端保存配置，固件本地计时；音频仍走 BLE，云端不能开麦。

基线 `53794c66`。现有主分支只包含 Wi-Fi 云端需求批 1，尚无设备 Wi-Fi 客户端与 Mac 配网/设备授权；本需求包含打通这条必要依赖，复用 [Wi-Fi 直连已确认方案](../desk-wifi-cloud-2026-11-03/README.md)。不修改其他 worktree 的内容。

## 契约与权限

- 新独立 scope `desk.configure`，可读取/保存本人轮播配置、读取应用状态、准备本人专用设备公开应用，不能拉取或确认设备指令。按后续免填需求，Mac 改用预置 Client ID 与本机钥匙串密钥，显式 `client_credentials` 且仅请求此 scope；访问令牌仅存内存，过期重新获取。旧 PKCE 控制授权保留，无预置密钥时仍可恢复。
- 设备继续使用**另一**本人专用公开应用（仅登记 `desk.sync`）。Mac 通过 `desk_prepare_device({})` 取得 `client_id`，再由本人在浏览器完成 PKCE 同意，经加密 BLE 交付设备 refresh token；Mac 不留存该 token，也不向设备交付控制端密钥，不放宽现有专用应用限制。
- `desk_prepare_device({})`（仅 `desk.configure`）返回 `{client_id}`，为当前所有者创建或复用本机制绑定的 public/PKCE 应用，只登记 `desk.sync`，回调固定 `http://127.0.0.1/callback`。迁移81保存owner绑定，重复/并发复用，计入每人20应用；不认领手工应用，停用/删除/改配置后失败，不恢复用户撤销，不生成grant/code/token。eval未绑定回空ID、已有绑定只读，不落生产记录。须先部署新API再在Mac点击「授权设备」，启动时不自动创建应用。
- 配置 JSON：`{revision,rotation_enabled,screens:[{kind,enabled,duration_seconds}]}`。数组恰含 `clock`、`mac_status`、`notifications` 各一项，数组顺序即展示顺序，至少启用一项，停留时间 5–300 秒。默认时长 10/15/20 秒、自动轮播开启，未保存时 revision=0。
- `desk_get_display({})`（`desk.configure`）与 `desk_set_display({expected_revision,rotation_enabled,screens})` 返回 `{config,applied_revision,online}`。保存采用版本比较，过期修改失败；内容未变不增加版本。
- `desk_pull` 可选输入 `display_revision`（设备已成功应用的版本，缺失不覆盖旧值），输出新增 `display`（完整配置）。旧客户端忽略新增字段，原有命令、ack 与 TTL 语义不变。
- BLE 新特征 8（write with response）：≤512 字节 JSON，`{op:"wifi",ssid,password}` 或 `{op:"grant",client_id,refresh_token}`；特征 9（read + notify）：无凭据的云端状态 JSON，包含 `wifi_connected,authorized,display_revision,error`。要求加密 + MITM；info 新增 `cloud 1`、`display 1` 能力行。
- dashboard 继续接受旧 10 字节，支持能力的设备可接受 12 字节（末尾 `mac_battery u8`，无电池/未知=255；`mac_power u8`，0未知/1电池/2外接电源/3充电）。旧 Mac/固件路径保留。

## 行为与恢复

设备每约 15 秒同步控制与配置，每约 10 分钟读取通知 feed。配置在设备本地原子替换并缓存，只有成功应用后才上报版本；相同版本不重启轮播。通知 TTL 是内容过期时间，独立于页面停留时间；最新文章、日报和未过期 agent 消息分别保留，不互相覆盖。通知页没有内容时跳过。关闭自动轮播并固定通知模板时，卡片仍按该页设置的秒数更换，避免第一条通知占满其他内容的有效期。

配对、讲话优先于轮播；讲话期间暂停云端联网，结束继续轮播。Mac 离线不阻断 Wi-Fi 内容，Mac 指标过期显示不可用；时钟使用校时后的本地单调计时。设备未联网保留最后配置，重启恢复，旧固件显示明确的不支持状态。网络、JSON、授权错误不阻断音频任务，不记录 SSID 密码或 OAuth token。
