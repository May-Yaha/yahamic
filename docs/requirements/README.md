# Yaha Desk 需求记录

本目录保存 Yaha Desk 从闭源 `yahaops` 迁回开源 `yahamic` 时一并迁移的需求、验收与验证记录。
记录按日期保留原目录名；迁移后新增需求只在本仓维护，不再回写闭源仓库。
历史正文里的 `yahaops-desk/`、`deploy/verify-gates.sh`、`yahaops-api/` 等名称描述当时的仓库布局与
联合验收事实，不是当前目录或依赖要求；现行客户端契约见[领域词汇](../domain-glossary.md)与
[云端契约](../cloud-contract.md)。个人绝对路径在公开迁移时已替换为占位符。
