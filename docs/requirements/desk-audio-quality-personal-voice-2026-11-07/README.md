# 桌面音频质量与本人声纹档案（2026-11-07）

## 目标与边界

1. 先消除 Mac 音频出口的真实欠载，再判断文字重复；传输、解码、渲染和 BlackHole 分阶段留证。
2. 在 Mac 端录制五句本人语音，质量合格后用本地 Core ML 模型生成本人声纹；原始语音默认只留本机，用户明确点“备份到网盘”才上传。
3. 本批不烧录固件，不把降噪等同于说话人过滤，也不默认启用实时过滤。多人同时说话需要目标说话人提取，只有声纹相似度门控不足以恢复重叠语音。

## 基线与根因判断

- 2026-11-02 的旧修复 `814e45c7` 处理的是 BlackHole 音量被调低和固件开麦首帧爆音；这两项修复仍保留，本次不是同一根因。
- 120 ms 旧基线在 60 秒 TTS 压测中，接收、解码、入队均零丢失，但 Mac 渲染欠载新增 4–5 次；是否同时录制诊断音频不改变结果。
- 因此 P0 根因位于渲染缓冲，不在文字后处理。候选策略将旧 60/120 ms 设置迁到 180 ms，并让起播预缓冲与目标水位一致。
- 诊断每 100 ms 采样水位，输出最小值、P05/P50/P95/最大值；每轮同时保存解码 PCM、BlackHole 实际输出、TTS 参考音和链路计数。

## 模型选择

- 声纹使用 [FluidAudio v0.17.7](https://github.com/FluidInference/FluidAudio/releases/tag/v0.17.7) 的本地 WeSpeaker 256 维 embedding；官方 API 支持从 16 kHz 单人语音提取 embedding，并明确该能力用于预登记说话人。
- 降噪候选是 [LocalVQE](https://github.com/FluidInference/FluidAudio/blob/v0.17.7/Documentation/Enhancement/LocalVQE.md)，但官方标记为 Beta；无扬声器参考时只做降噪/去混响，不能当作目标说话人过滤。本批只保留离线 A/B 入口，达到真人语料指标后才考虑默认接入实时链路。
- Google VoiceFilter-Lite 的公开说明是识别特征过滤而非通用干净波形输出，且原始模型未公开，不作为本批可交付依赖。

## 真机验证结果

- 最终复核版 3×60 秒：累计接收/解码/入队 3008 帧，输出 3005 帧；丢帧、无效包、解码错误、溢出和欠载均为 0。缓冲水位每 100 ms 直接读取抖动缓冲区，三轮最低水位 63.81 ms、最低 P05 117.38 ms、最低 P50 167.97 ms、最高 P95 215.78 ms、最高水位 242.44 ms。
- 10 分钟连续测试：接收/解码/入队 10517 帧一致，输出 10516 帧，丢帧、无效包、解码错误、溢出和欠载均为 0。该轮水位取自旧的约 1 Hz 状态缓存，不能证明 100 ms 采样分布，相关分位数不再作为验收证据；修正后的直接采样证据以上述 3×60 秒为准。
- 长测的 `nc` 原收尾预算只有 15 秒，且相对休眠累计了约 31 秒调度偏差，导致外层脚本在 App 返回前退出；核心链路结果和 WAV 已由 App 日志/采集留下。超时已改为“时长 + 20% + 60 秒”，采样调度改为绝对时钟。最终 3×60 秒脚本逐轮完整退出，BlackHole 采集统一为精确 62 秒，避免把无信号间隙从文件时长中压掉。
- LocalVQE v1.3 无参考离线 A/B：解码音频语音段从 27 降到 6，静音占比从 56.67% 升到 96.46%，RMS 下降 8.69 dB。该远场 TTS 样本上过度抑制，不放入实时链路；待五段本人近场语音重新评估。
- 隐私竞态修复后的 30 秒回归：接收/解码/入队 498 帧，输出 495 帧，丢帧、无效包、解码错误、溢出和欠载均为 0；最低水位 86.44 ms、P05 126.37 ms、P50 180.69 ms、P95 223.27 ms。结束后设备确认静音，下一次采集可立即获取门闩，说明原模式恢复完成。
- 压测与声纹采集进入私密采集态时，普通录音备份停止接收音频；结束时门闩保持到 Uplink 同一串行队列确认设备静音，确保在途尾帧先排空。最终回归后 `Recordings/` 文件数仍为 0，未触发自动网盘录音备份。

## 隐私与数据生命周期

- 本人声纹档案包含五段 16 kHz WAV、256 维 embedding、质量结果和模型版本，默认位于 `~/Library/Application Support/YahaDesk/VoiceProfile/`。
- “备份到网盘”是显式动作，路径为 `/apps/拾见/录音/声纹/<profile-id>/`；不因登录网盘或普通录音备份而自动上传。
- 删除档案先清除本机 WAV 和 embedding；如果存在云端备份，界面再次询问是否同时移入网盘回收站。网盘失败时只保留不含生物特征数据的远端路径回执供重试，并明确显示“本机已删除，网盘待处理”。

## 烧录与真机生效记录

- 2026-11-07 用户后续明确授权烧录。使用 ESP-IDF 6.1 从 `main` 提交 `97579635` 构建并写入设备 `yahadesk-222a`；只写 bootloader、分区表和应用，不擦除 NVS，也不写独立 `fac` 分区。
- 烧录写入与 SHA 校验通过，启动日志确认固件 0.3.0、16 MB Flash、8 MB PSRAM、CST9220 触摸、ES7210 + Opus 16 kHz/60 ms、BLE 加密连接和 Wi-Fi 恢复正常。
- 烧录后 30 秒压测：接收、解码、入队、输出均为 497 帧；无效包、解码错误、跳号、丢帧、溢出和欠载均为 0。缓冲最低 60.56 ms、P05 125.23 ms、P50 163.78 ms、P95 199.19 ms；结束后恢复静音待命，普通录音目录仍为 0 个文件。
